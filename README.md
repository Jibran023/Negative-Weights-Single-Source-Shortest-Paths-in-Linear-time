# Negative-Weights-Single-Source-Shortest-Paths-in-Linear-time

This project addresses the challenge of efficiently finding shortest paths in graphs containing negative edge weights—a critical problem in logistics, finance, and network optimization. Traditional methods like the Bellman-Ford algorithm guarantee correctness but suffer from slow O(mn) runtime, while recent advancements rely on complex optimization frameworks. The authors introduce a novel combinatorial approach that achieves near-linear time (O(mlog^6 nlogW)) by combining three key techniques: price functions to transform edge weights into non-negatives, low-diameter decomposition to partition the graph into manageable clusters, and recursive scaling to iteratively eliminate residual negative weights. By avoiding intricate continuous optimization and focusing on graph-theoretic principles, this method simplifies implementation, enhances scalability, and broadens practical applicability, offering a faster, more accessible solution for detecting shortest paths or negative cycles in real-world systems like route planning with toll rebates or arbitrage detection.
